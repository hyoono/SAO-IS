# SAO-IS Deployment Guide

Detailed deployment instructions for the SAO-IS system.

See the main deployment guide in the Agent Instruction Manual for step-by-step instructions.

## Quick Reference

1. Fix server IP (DHCP reservation or static)
2. Install WSL2 + Ubuntu 22.04
3. Auto-start WSL2 on boot
4. Configure WSL2 port proxy
5. Install stack (Nginx, PHP 8.2, MySQL, Node.js 20)
6. Configure Nginx
7. Deploy application
8. Set up scheduler + queue worker
9. Security hardening
10. Automated backups
