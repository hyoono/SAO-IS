# SAO-IS Organization Officer User Guide

## Overview

As an **Organization Officer**, you can submit documents on behalf of your student organization — event proposals, accreditation forms, activity reports, and other org-related paperwork.

## Getting Started

1. Open `http://<server-address>` in your browser
2. Login with your org officer credentials
3. You'll be directed to the Org Officer Dashboard

## Dashboard

Your dashboard shows:
- **My Submissions** — count of org documents submitted
- **Pending** — documents awaiting review
- **Approved** — approved org documents

## Submitting Organization Documents (`/submit`)

1. Click **Submit** in the sidebar
2. Select the **Document Type** (e.g., "Event Proposal", "Org Accreditation")
3. Enter a descriptive **title** (e.g., "IEEE MMCL Chapter - Annual Report 2026")
4. Attach the required file
5. Click **Submit document**

> **Tip:** Use clear, descriptive titles that include your organization name for easy tracking.

## Tracking Submissions (`/my-submissions`)

1. Click **My Submissions** in the sidebar
2. Monitor the approval progress of each document
3. Status meanings:
   - **In Review** — being processed through approval steps
   - **Awaiting Info** — reviewer needs additional information
   - **Approved** — fully approved
   - **Rejected** — rejected (check notifications for reason)

## Responding to Revision Requests

If a reviewer requests changes:
1. Check your notifications for the specific request
2. Open the document detail page
3. Upload a revised version
4. The document re-enters the review queue

## Browsing Documents (`/documents`)

- View all documents you have access to
- Search and filter to find specific submissions

## Notifications

- Bell icon in topbar shows unread count
- Notifications auto-mark as read when page is opened
- Click **View document →** to jump to the relevant document
