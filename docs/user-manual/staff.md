# SAO-IS Staff User Guide

## Overview

As a **Staff** member, you can review and approve documents, manage document types, configure workflows, and access the document archive.

## Getting Started

1. Open `http://<server-address>` in your browser
2. Login with your staff credentials
3. You'll be directed to the Staff Dashboard

## Dashboard

Your dashboard shows:
- **Pending Reviews** — documents waiting for your approval
- **Documents Processed** — your approval history count
- Quick action links to key pages

## Reviewing Documents (`/approvals`)

1. Click **Approvals** in sidebar
2. Documents assigned to the Staff step appear here
3. Click **Review →** on a document
4. Review the document details:
   - Submitter name, submission date
   - Attached file — click **Download** to view
   - Previous approval history
5. Enter optional remarks, then:
   - **Approve** — advances to next step
   - **Reject** — rejects the document
   - **Request Info** — asks submitter for more info

## Managing Document Types (`/admin/document-types`)

1. Click **Document Types** in sidebar
2. View existing types with their workflow assignments
3. Click **+ New Type** to create a new category
4. Click **Edit** to modify existing types

## Managing Workflows (`/workflows`)

1. Click **Workflows** in sidebar
2. View existing workflow templates
3. Create new workflows with **+ New Workflow**
4. Edit existing workflows via the detail page → **Edit**

## Browsing Documents (`/documents`)

- View all documents in the system
- Use the search bar to find documents by title
- Use filters (status, type, date range) to narrow results
- Click **View →** to see document details and version history

## Submitting Documents (`/submit`)

Staff can also submit documents:
1. Click **Submit** in sidebar
2. Select document type, enter title, attach file
3. Click **Submit document**

## Archive (`/admin/archive`)

- View archived documents (expired or manually archived)

## Notifications

- Bell icon shows unread count
- Notifications auto-mark as read when page is opened
